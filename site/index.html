Download the APK.

Signed builds for Android 9 or newer are on GitHub Releases; the current one, 0.1.0-rc.1, is a release candidate. The app installs the Beacon its release pins on a Host, from the Host's settings.

Get it on GitHub Releases

Or build it from source with Rust, Java 21 and the Android SDK with NDK 27.

git clone https://github.com/shiro-el/aries.git
cd aries/android
./gradlew :app:assembleDogfood -Paries.abis=arm64-v8a
adb install app/build/outputs/apk/dogfood/app-dogfood.apk
